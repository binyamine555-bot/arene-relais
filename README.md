# Relais en ligne — Arène des Origines

Relais du mode en ligne, hébergé sur Render (offre gratuite).
- iPhone / navigateur : WebSocket sécurisé sur `wss://<service>.onrender.com/`
- Android : TCP via le tunnel `bore.pub:50055`

Le relais ne lit rien : les parties et messages sont chiffrés de bout en bout entre les joueurs.
